Privacy Policy — Eighteen Translator

Last updated: 18 October 2026 · Applies to Eighteen Translator (Manifest V3). The optional free service is available only after deployment and configuration.

In one paragraph. The extension processes only text you select. Own-key mode sends it directly to DeepSeek or Google's public translation endpoint. When enabled, free mode sends the selection, target language and a random browser-installation identifier to the project's Cloudflare-hosted service, which forwards the text to DeepSeek and records the daily allowance. Your own API key is never sent to the free service. No account, advertising analytics or browsing-history collection is required.

1. What this extension does

The extension has a single purpose: translate text you select on a web page. You select text; a small panel shows the translation. Nothing else is translated or collected.

2. What data is processed

DataWhenWhy
The text you selected on the page Only when you select text (automatic mode) or click the trigger dot (manual mode) It is the input to translation. Nothing else on the page is read.
Your translation settings When you change them Source/target language, engine choice, panel appearance, read-aloud settings.
Your API key Only if you choose the DeepSeek engine and enter a key Sent to DeepSeek to authenticate your own requests.

The extension does not read page content beyond your selection. It does not record which pages you visit, and it does not build any history of your translations.

3. Where your text is sent

Selected text leaves your device when you request a translation. Own-key mode uses one of these engines:

EngineDestinationNotes
DeepSeek (own-key default) https://api.deepseek.com Uses the API key you supply. DeepSeek's own privacy policy governs their handling of the request.
Google (free public endpoint) https://translate.googleapis.com An unofficial public endpoint with no account or key. Not reachable from mainland China networks and often rate-limited on shared IPs.

Free mode contacts https://eighteen-translator-api.eighteentang.workers.dev, declared in manifest.json under host_permissions. The service receives the selected text, target language and installation identifier, and forwards the text to DeepSeek. No page URL, browsing history or user-supplied API key is included.

The project service does not persist selections or translations. It stores short-lived daily quota records linked to a hashed installation identifier. Cloudflare processes connection metadata such as IP addresses; the service uses transient network metadata for request handling without storing the original IP. Cloudflare and DeepSeek have their own infrastructure, retention and privacy policies.

4. What is stored on your device

Settings, your API key and the translation cache live in chrome.storage.local. They are not uploaded to the project service. Free mode additionally stores a random installation identifier locally and sends it to the service to obtain the daily allowance; the latest returned allowance is cached locally.

  • Your settings — languages, engine choice, panel appearance, read-aloud options, excluded sites.
  • Your API key, if you entered one.
  • Usage counters — how many translations you ran today. Kept for the last 30 days.
  • A translation cache — up to 200 recent translations, expiring after 7 days, so repeated selections do not hit the network again.

Your API key is stored in plain text. It is not encrypted. Anyone who can read your browser profile directory on this computer can read it. Your key is not synced to cloud storage. The show/hide toggle in the settings page only masks it on screen — it is not encryption.

Settings are not synced across devices. If you install the extension on another computer you will need to configure it again. This is deliberate: syncing would put your API key into your browser vendor's account storage.

5. What is NOT collected

  • No browsing history, no list of visited pages, no page content beyond your selection.
  • No advertising analytics, tracking telemetry or crash reporting. Local usage counters and the free service's daily quota records are used for the features described above.
  • No account, email address or name is requested. Free requests use a random installation identifier, not a verified personal identity.
  • No advertising, no tracking pixels, no third-party scripts on this page or in the extension.
  • Data is not sold or rented. The providers above process requests needed for translation.

The extension contains no remote code. All executable code ships inside the package; it never downloads or evaluates code at runtime.

6. How to delete your data

  • Clear the translation cache: settings page → Usage section → clear cache.
  • Remove your API key: settings page → clear the key field.
  • Delete local data: uninstall the extension (edge://extensions or chrome://extensions). This removes its local settings, API key, cache and installation identifier. It does not immediately erase provider-side records.
  • Free-service records: the service schedules deletion of inactive daily quota records after their short retention period. Cloudflare storage recovery and provider infrastructure can have separate retention periods. Uninstalling the extension does not signal the server.

7. Permissions and why they are needed

PermissionWhy
storageTo save your settings, key, counters and cache locally.
https://api.deepseek.com/*, https://translate.googleapis.com/*To send the selected text to the engine you chose.
Content script on <all_urls>Select-to-translate only works if the extension is present on the page where you select text. Without this, it would have to be enabled per site, which defeats the purpose.

Builds with free mode enabled also declare the deployed project-service origin so requests can reach it. The extension requests no account, payment or browsing-history permissions.

8. Children

This extension is a general-purpose translation tool and is not directed at children. Do not include sensitive personal information in text you send to translation providers.

9. Changes to this policy

If the extension's data handling changes, this page will be updated and the "last updated" date above will change. Material changes — for example, adding any form of analytics — will also be noted in the extension's changelog.

10. Contact

Questions, corrections or concerns: please open an issue at github.com/eighteentang/eighteen-translator/issues.

隐私政策 —— 划词翻译（Eighteen Translator）

最后更新：2026 年 10 月 18 日 · 适用于 Eighteen Translator（Manifest V3）。可选的免费服务在部署并配置后开放。

一句话说清。本扩展只处理你主动选中的文字。自带 Key 模式直接访问 DeepSeek 或 Google 公共翻译接口；免费模式开放后，会把选中文字、目标语言和随机浏览器安装标识发送到本项目托管于 Cloudflare 的服务，再转发给 DeepSeek，并记录当天额度。你自己的 API Key 不会发送到免费服务。不注册账号，不收集浏览历史，没有广告统计埋点。

1. 这个扩展做什么

单一用途：翻译你在网页上选中的文字。你选中文字，浮层显示译文。除此之外不翻译、不收集任何东西。

2. 处理哪些数据

数据什么时候为什么
你在页面上选中的文字 仅在你选中文字时（自动模式），或点击触发小圆点时（手动模式） 它是翻译的输入。页面上的其他内容一概不读。
你的翻译设置 你修改时 首选 / 目标语言、引擎选择、浮层外观、朗读设置。
你的 API Key 仅当你选择 DeepSeek 引擎并填入 Key 时 发往 DeepSeek，用于认证你自己的请求。

本扩展不读取选中内容之外的页面内容，不记录你访问过哪些页面，也不保留任何翻译历史。

3. 文字发到哪里

你请求翻译时，选中文字会离开设备。自带 Key 模式使用下面一个引擎：

引擎目标域名说明
DeepSeek（自带 Key 模式默认） https://api.deepseek.com 使用你提供的 API Key。请求在 DeepSeek 侧的留存与处理，适用 DeepSeek 自己的隐私政策。
Google（免费公共接口） https://translate.googleapis.com 非官方公共端点，无需账号与 Key。中国大陆网络不可达，共享出口 IP 常被限流（返回 429）。

免费模式访问 https://eighteen-translator-api.eighteentang.workers.dev，该地址已在 manifest.json 的 host_permissions 中声明。后台接收选中文字、目标语言和安装标识，并把文字转发给 DeepSeek；不包含页面网址、浏览历史或用户自带的 API Key。

项目服务不保存原文或译文，只保存关联到安装标识散列值的短期每日额度记录。Cloudflare 会处理 IP 等连接信息；服务临时使用网络信息处理请求，不保存原始 IP。Cloudflare 和 DeepSeek 各自有独立的基础设施、留存规则与隐私政策。

4. 本机存了什么

设置、用户 API Key 和译文缓存保存在 chrome.storage.local，不上传到项目服务。免费模式另外在本地生成随机安装标识，发送该标识查询和使用每日额度，并在本地缓存服务端返回的额度状态。

  • 你的设置 —— 语言、引擎、浮层外观、朗读选项、排除站点。
  • 你的 API Key（如果你填了）。
  • 用量计数 —— 今天翻译了多少次。只保留最近 30 天。
  • 译文缓存 —— 最多 200 条、7 天后过期，避免反复划同一段文字时重复请求。

你的 API Key 是明文存储的，没有加密。能读到这台电脑上浏览器配置目录的人就能看到它。用户 Key 不会同步到云端存储。设置页的「显示 / 隐藏」只遮住屏幕，不是加密。

配置不跨设备同步。换台电脑要重新配置。这是刻意的：一旦同步，你的 API Key 就会进到浏览器厂商的账号存储里。

5. 不收集什么

  • 不收集浏览历史、不记录访问过哪些页面、不读取选中内容之外的页面内容。
  • 没有广告统计、跟踪埋点或崩溃上报。本地用量计数及免费服务每日额度记录仅用于上述功能。
  • 没有账号、不索取邮箱与姓名。免费请求使用随机安装标识，不核验真实个人身份。
  • 没有广告、没有跟踪像素；本页与扩展里都没有第三方脚本。
  • 不出售或出租数据；上述服务提供方会处理翻译所需的请求。

扩展内没有远程代码。所有可执行代码都随包一起分发，运行时不会下载或执行任何外部代码。

6. 怎么删掉你的数据

  • 清译文缓存：设置页 →「用量」一节 → 清空缓存。
  • 删除 API Key：设置页里把 Key 清掉即可。
  • 删除本地数据：卸载扩展（edge://extensions 或 chrome://extensions），浏览器会删除本地设置、Key、缓存及安装标识。此操作不会立即删除服务提供方的记录。
  • 免费服务记录：后台会在短期保留后安排清理不活跃的每日额度记录。Cloudflare 的存储恢复机制及提供方基础设施可能有独立保留期。卸载扩展不会通知服务端。

7. 申请的权限及理由

权限为什么需要
storage在本机保存你的设置、Key、计数与缓存。
https://api.deepseek.com/*、https://translate.googleapis.com/*把选中的文字发给你选择的引擎。
内容脚本匹配 <all_urls>划词翻译必须能在你选字的那张页面上工作。若改成按站点启用，就失去了「选中即译」的意义。

开放免费模式的版本还会声明真实项目服务域名权限，以便发送免费翻译请求。扩展不申请账号、支付或浏览历史权限。

8. 关于儿童

本扩展是通用翻译工具，不面向儿童。请勿在发往翻译服务的文字中包含敏感个人信息。

9. 政策变更

若数据处理方式发生变化，本页会更新，「最后更新」日期也会改。涉及实质性的变化（例如将来加入任何形式的统计）还会记进扩展的更新日志。

10. 联系方式

有任何疑问或需要更正，请在 github.com/eighteentang/eighteen-translator/issues 提一个 issue。
